# Slack Essentials

Slack by voice. Connect Slack, install this plugin, and say:

- "Catch me up on #design"
- "Find the message where Sam shared the launch date"
- "Tell #general the deploy is done"
- "Remind me in Slack to send the report at 4"

## What it can do

| Skill | Uses |
|---|---|
| Catch up on a channel | finds the channel, reads recent messages |
| Find a message | searches your workspace |
| Send a message | finds the channel or person, posts the message |
| Set a reminder | creates a Slack reminder for you |

It posts only when you ask it to.
