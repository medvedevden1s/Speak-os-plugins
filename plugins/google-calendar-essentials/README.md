# Google Calendar Essentials

Your calendar by voice. Connect Google Calendar, install this plugin, and say:

- "What's on my calendar today?"
- "When am I free on Thursday afternoon?"
- "Book a call with Anna tomorrow at 3 for 30 minutes"
- "Move my dentist appointment to Friday"

## What it can do

| Skill | Uses |
|---|---|
| Today's agenda | reads your events |
| Find free time | reads your free and busy times |
| Schedule an event | finds a free slot, creates the event |
| Move an event | finds the event, changes its time |

It creates or moves an event only when you ask it to. The **Daily agenda** agent only reads.

## Agents

- **Daily agenda** — your day in a few lines: meetings, gaps, and anything that needs preparation.
