# Gmail Essentials

The everyday email skills for Speak OS. Connect Gmail, install this plugin, and say:

- "Catch me up on my email"
- "Find the email from Anna about the invoice"
- "Draft a reply to the last email from my accountant"
- "Email Sam that I'll be ten minutes late"

## What it can do

| Skill | Uses |
|---|---|
| Summarize unread email | reads your inbox |
| Find an email | reads your inbox |
| Draft a reply | reads a thread, creates a draft (never sends) |
| Send an email | looks up the contact, sends the email |
| Reply to a thread | sends a reply in an existing thread |

It sends or drafts only when you ask it to. The **Morning inbox digest** agent only reads.

## Agents

- **Morning inbox digest** — a short summary of what arrived overnight and what needs a reply today. Add it from the plugin, then give it a schedule in Planner.
